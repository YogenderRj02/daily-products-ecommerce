# DailyNest – Daily Products E-commerce App

A modern e-commerce storefront for everyday essentials including groceries, personal care, home care, and wellness products.

## Features

- Product catalog with category filters
- Search by product name
- Product detail modal
- Shopping cart with quantity updates
- Checkout flow with order confirmation
- Responsive storefront layout
- Node.js + Express API
- React + Vite frontend

## Tech Stack

- Frontend: React, Vite, CSS
- Backend: Node.js, Express
- API: RESTful endpoints with in-memory product data

## Getting started

1. Install dependencies
   ```bash
   npm install
   cd client && npm install
   ```
2. Start the app in development mode
   ```bash
   npm run dev
   ```
3. Open the app in your browser
   - Frontend: http://localhost:5173
   - API: http://localhost:5000/api/health

## Production build

```bash
npm run build
```

## Notes

This app uses mock product data and a lightweight backend so it can run immediately without a database setup.
